# AgriMine – Precision Agriculture (DWM prototype)

## How to run
    pip install -r requirements.txt
    streamlit run app.py

Real dataset: put the Kaggle "Crop Recommendation" CSV at `data/Crop_recommendation.csv`.
If it is missing, a synthetic dataset with the same columns is generated automatically.
